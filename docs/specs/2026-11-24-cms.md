# CMS

- **Status:** done
- **Date:** 2026-11-24
- **Pages / modules:** `/cms/*`, `client/features/admin`
- **Requested by:** owner

## Summary

An owner area at `/cms` that moves between all four pages and edits each in the page's own design, so the admin still feels the real UI.

## Scope

**In scope**

- `/cms/landing`, `/cms/menu`: the public design with controls; products create, edit, archive, delete, availability, featured (picks), image upload, filters and search, live card preview in the form.
- `/cms/recipes`, `/cms/sales-tracker`: the existing pages, which already create, edit and delete.
- Collapsible sidebar with a link per page (drawer on phones); login now lands on `/cms`.
- Saves refresh the public pages' cache at once.

**Out of scope**

- Business settings (name, tagline, phone, hero image), category rename/reorder/delete, drag-to-reorder products.

## Design

See `docs/architecture/admin.md`. A category can be created inline from the product form, because products can't be added to an empty menu otherwise.

## Open questions

- Settings editor and category manager are the next candidates.
- The admin gate is client-side; the API's `requireAuth` is the real protection.
