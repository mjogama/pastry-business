# Menu and Landing on the server, with Cloudinary images

- **Status:** done
- **Date:** 2026-11-24
- **Pages / modules:** `/`, `/menu`, `server/src/modules/{categories,products,menu,media}`
- **Requested by:** owner

## Summary

Replace the menu's seed data with an API and database, and add Cloudinary for product and hero images. Follows the recipes and sales-entry structure (schema, repository, service, controller, routes, module), with each module's own rules instead of copied code.

## Scope

**In scope**

- `categories`: list, get, create, patch, delete (`/api/v1/categories`).
- `products`: list (`limit`, `categoryId`, `includeArchived`), get, create, patch (`null` clears an optional field), delete (`/api/v1/products`).
- `menu`: `GET /menu` (settings, categories, non-archived products), `GET` and `PUT /menu/settings`.
- `media`: `POST /media/images` (multipart field `image`, JPG/PNG/WebP, ≤ 5 MB) to Cloudinary.
- Reads are public; every write needs the owner session.
- Client: `api.ts`, `lib/normalize.ts`, cached `data/menu-data.ts`, error and empty states, `images.remotePatterns`.

**Out of scope**

- An owner UI for products, categories, settings and uploads (the API is ready for it).
- Deleting replaced or orphaned Cloudinary images.
- Importing the old seed data.

## Design

- Why not copied from recipes: products and categories patch partial updates, enforce cross-field rules against the stored row, and categories can't be deleted while used; settings is a single upserted row; media stores nothing in the database.
- Ids are UUID v7 strings. Money is `DECIMAL(10,2)`; `discountEndsAt` is a `DATE` (Manila day).
- `UpdateProductInput` in `shared/modules/product.ts` now lets `null` clear `description`, `imageUrl`, `discountPrice` and `discountEndsAt`.
- Image URLs must be `https://res.cloudinary.com/...` (`cloudinaryUrl` in `shared/validation/primitives.ts`). Uploads are checked by their first bytes, not the declared type, and kept in memory.
- Cloudinary env vars are optional; without them uploads answer 503 and everything else works.
- Settings default to the business name with no tagline and no contact number until saved.

## Open questions

- Which owner screen comes first: Products manager or Settings?
- Should replaced images be deleted from Cloudinary?
- Menu changes show after the 5-minute cache window; add an on-demand refresh when the owner UI exists.
